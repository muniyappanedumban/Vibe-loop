# VibeLoop "Prism Pulse" design system

Original style mixing a short-video creator aesthetic (bold 9:16 tiles, dark hero cards) with an AI-assistant aesthetic (soft surfaces, chat bubbles, glow). No third-party brand assets.

| Token | Value | Use |
|---|---|---|
| bg | #F4F2FA | app background (light default) |
| surface | #FFFFFF | cards |
| ink | #120F24 | text, dark hero cards, tab bar |
| inkSoft | #6B6785 | secondary text |
| line | #E7E3F3 | borders |
| violet | #6C3BFF | primary |
| pink | #FF3D9A | secondary accent |
| tangerine | #FF8A3D | warm accent |
| lime | #C8F45A | highlight / success-on-dark |
| mint | #2BD9A8 | success |
| danger | #FF4D5E | errors |
| gradient "prism" | violet → pink → tangerine (135deg) | CTAs, score rings |

Radius: 12 / 20 / 28 / pill. Font: system, weights 600–800 for headings, tight letter-spacing (-0.5).
Signature elements: floating ink pill tab bar with a prism "create" orb; Loop Score ring; "Vibe" reaction stickers (Spark = would share, Drift = would skip, Bolt-fix = needs work, Heart-dot = this is for me).
